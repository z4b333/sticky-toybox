Already have a list?

Paste it here and it fills the table. One card a line, with the front and the back separated by a tab, a |, a comma or - . That covers an Anki export, a Quizlet export, and a column pair copied out of a spreadsheet. A first line reading front,back (or term,definition) is treated as column titles and dropped, exactly as the device does.

Getting it onto the device

  1. Put the microSD card in a computer. It has to be FAT32 — the same card the books and pictures live on.
  2. Make a folder called notes or decks at the top of the card if it is not there yet, and drop the file in it.
  3. On the device, open NOTES or FLASHCARDS and press CARD. Tap the file and it comes in.

Bringing in a note or a deck of a name the device already has replaces it. For a deck, the cards you had already learned keep their place in the spaced-repetition boxes, as long as the front text has not changed — so a deck can be edited here and dropped back without losing progress.

The device also takes both of these over its own wifi, from a phone: WRITE in the notes app, IMPORT in the flashcards app. This page is for when the card is easier than the phone, or when the note is long.
