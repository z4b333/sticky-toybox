TOYBOX

◆   ◆

Games and small tools for the Seeed reTerminal Sticky — Wordle, Nonogram, 2048, Sudoku, Battleship, XO, dice and coins, a timer, flashcards and fridge-notes you write from your phone. Notes and flashcards speak English, Thai, Chinese, Korean, Japanese and Vietnamese.

FLASH FROM THIS PAGE

This browser has no WebSerial. Use Chrome or Edge on a computer — phones and Firefox/Safari cannot flash.

Plug the Sticky in over USB-C first. The full install erases the device and takes about a minute.

IF NO PORT SHOWS UP

  1. The Sticky talks through a CH34x USB-serial bridge — Windows and older macOS may need the CH343 driver.
  2. Use a data USB-C cable, not a charge-only one.
  3. If it still refuses: hold the power button while plugging in to enter the bootloader, then try INSTALL again.

AFTER FLASHING

  1. The hub appears. Tap a tile to play; the gear hides apps you don't want.
  2. Open NOTES → WRITE and scan the QR with your phone to write or dictate your first note. PIN it and it stays on the panel with the power off.
  3. First boot formats the 11.9 MB filesystem — give it a few extra seconds, once.

First time on real hardware? The full checklist is in BRINGUP.md.

PREFER A CABLE AND A TERMINAL?

esptool --chip esp32s3 write_flash 0x0 toybox-full.bin
The image is firmware/toybox-full.bin (bootloader + partition table + app, merged). Source, docs and the host-side screen previews live in the repository.
