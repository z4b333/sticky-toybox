A screen that keeps what you put on it.

Toybox is firmware for the Seeed reTerminal Sticky: an e-book reader, a notes board you write to from your phone, and a drawer of small games. The panel holds its last picture with the power off, so a pinned note stays readable on the fridge for months.

What it does

Six screens, out of about eighty.

Every picture here is rendered by the firmware itself, at the panel's own 480×800, by the test harness that ships with the source — so this is what the device draws, not a mockup of it.

Install

Flash it from this page.

Plug the Sticky in with a data-capable USB-C cable and press a button. Nothing to download, nothing to install on your computer.

UPDATE writes only the firmware itself: settings, stats, saved reading pages, notes, decks, pictures and font packs all stay exactly as they were. Use it for every build after your first. FIRST INSTALL also writes the bootloader and partition table — needed once on a new device, or if an update ever refuses to boot. Neither erases your notes. When the dialog asks about erasing the device, leave the box unchecked — ticking it wipes notes, settings and font packs. Both need Chrome or Edge and a USB-C data cable; the serial console opens when the write finishes, and that first-boot log is the most useful thing to send if anything goes wrong.

After installing

Two minutes, once.

The service screen is worth visiting before anything else: it reports what the board answered on each bus, and it can correct the screen or touch orientation if your unit disagrees with mine.

  1. The first boot takes a few extra seconds while it sets up storage.
  2. Hold either side button while it powers on the first time. That reaches the service screen; there is a tickable checklist for a phone held next to the device.
  3. Tap any tile on the hub to play.
  4. Open Notes → Write, scan the QR code with your phone, and type or dictate a note.
  5. Pin a note and it stays on the screen even with the power off. That is the whole idea.

If something goes wrong

Help.

No serial port showing up?
  • Use a data-capable USB-C cable, not a charging cable.
  • On Windows, install the CH343 driver. The Sticky uses a CH34x serial chip.
  • Still nothing? Hold the power button while plugging in, then try Install again.
Prefer the command line?

Update, keeping everything:

esptool --chip esp32s3 write_flash 0x10000 toybox-app.bin

First install (also writes bootloader and partition table; note this one resets the device's settings):

esptool --chip esp32s3 write_flash 0x0 toybox-full.bin

Download toybox-app.bin or toybox-full.bin.

Will an update wipe my notes?

No. Every part is written at its own offset and the gaps between them are never touched: settings and saved reading pages live in NVS, notes and decks and pictures in the filesystem, and neither is in the firmware's way. The one thing that does wipe them is ticking the erase device box in the browser's dialog, which is why it is worth reading that dialog rather than clicking through it.
