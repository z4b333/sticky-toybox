Needs Chrome or Edge on a computer, and a USB-C data cable. Erases the device.

After installing

  1. The first boot takes a few extra seconds while it sets up storage.
  2. Hold either side button while it powers on the first time. That reaches the service screen, which says what the board answered on each bus and can correct the screen or touch orientation if your unit disagrees with mine. Worth two minutes before anything else; there is a tickable checklist for a phone held next to the device.
  3. Tap any tile on the hub to play.
  4. Open Notes → Write, scan the QR code with your phone, and type or dictate a note. Works in English, Thai, Chinese, Korean, Japanese and Vietnamese.
  5. Pin a note and it stays on the screen even with the power off. That is the whole idea.
No serial port showing up?
  • Use a data-capable USB-C cable, not a charging cable.
  • On Windows, install the CH343 driver. The Sticky uses a CH34x serial chip.
  • Still nothing? Hold the power button while plugging in, then try Install again.
Prefer the command line?

esptool --chip esp32s3 write_flash 0x0 toybox-full.bin

Download toybox-full.bin. It's a single merged image (bootloader, partition table and app), flashed to offset 0.
