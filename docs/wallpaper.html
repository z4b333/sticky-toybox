Wallpaper maker

Turns any picture into the device's own format, entirely in this browser — nothing is uploaded anywhere. What you see below is exactly what the panel will show: 480 × 800, one bit per pixel.

Put the file in /wallpapers on the SD card (or the card's root). On the device: settings → Wallpaper, or settings → Lock screen → THE PICTURE → FROM CARD — choosing one copies it into the device, so the card can come back out. You can also send it through Files over WiFi.

The same file works as a book cover: name it <book name>.cover.tbi and put it beside the book in /books — it beats anything the device can decode.
