.tbi goes in /wallpapers (or the card's root): on the device, settings → Wallpaper or Lock screen → FROM CARD. Named <book name>.cover.tbi beside a book it becomes that book's cover.

BMP grey is the pretty one for the sleeping screen: save it as /sleep.bmp (or drop several in /.sleep/ for a random one each time) and the panel shows it in real four-level grey at power-off. Chosen from the wallpaper list, a BMP lock picture also keeps its greys. The same files work on the Xteink X3/X4 and CrossPoint/CrossInk/matcha family.
